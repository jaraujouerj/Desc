## Objetivos
Ao final do período, o aluno deverá ter assimilado os conhecimentos e técnicas utilizadas para a modelagem e projeto de um banco de dados.

## Ementa
Introdução a Banco de Dados. Sistemas Gerenciadores de Banco de Dados. Modelagem de banco de dados. Modelagem conceitual com modelo Entidade-Relacionamento (MER). Modelo Relacional. Álgebra Relacional. Normalização. Linguagem SQL. Ferramentas Case. Tendências.

## Bibliografia básica
- DATE, C.J. *Introdução a sistemas de bancos de dados*. ELSEVIER EDITORA, 2004.
- ELMASRI, R.; NAVATHE, S.B. *Sistemas de Banco de Dados*. Pearson Universidades, 2019.
- SILBERSCHATZ, A.; SUNDARSHAN, S.; KORTH, H.F. *Sistema de Banco de Dados*. Elsevier, 2016.
