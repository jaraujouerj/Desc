## Objetivos
Ao final do período, o aluno deverá ser capaz de criar, editar, compilar, corrigir e depurar programas de computador numa linguagem de programação de alto nível.

## Ementa
Introdução aos Sistemas Operacionais da família UNIX. Linguagem C ANSI. Ferramentas para desenvolvimento, compilação, correção e depuração de programas. Programação para UNIX. Manipulação de estruturas de dados usando ponteiros.

## Bibliografia básica
- DAMAS, L.M.D. *LINGUAGEM C*. 10a. Edição. LTC, 2007.
- GUSTEDT, J. *Modern C*. Manning, 2019.
- KERNIGHAN, B.W.; RITCHIE, D.M. *C: a linguagem de programação padrão ANSI*. Campus, 1989.
- NEVES, J.C. *Programação Shell Linux (7a. edição)*. 9a. Edição. BRASPORT, 2013.
